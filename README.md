# Credit Card Fraud Detection (SVM)

A machine-learning project detecting fraudulent credit-card transactions
using a Support Vector Machine, on a strongly imbalanced dataset (fraud is
a tiny fraction of all transactions).

## What it covers
- Preprocessing and scaling of transaction features.
- Handling severe class imbalance.
- Training and tuning an SVM classifier.
- Evaluating with precision, recall, and F1 (accuracy alone is misleading
  when one class is rare).

## Files
- `Credit_Card_Fraud_Detection.ipynb` — full analysis and model.
- `SVM_Project.pdf` — written report.
